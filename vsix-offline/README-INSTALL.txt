================================================================================
  ОФЛАЙН-УСТАНОВКА РАСШИРЕНИЙ VS CODE
  Машина A (интернет) -> флешка -> Машина B (Windows, без интернета)
================================================================================

  Что в папке:

    ruff-win32-x64.vsix   линтер/форматтер Ruff v2026.66.0 (сборка под Windows x64!)
    one-dark-pro.vsix     тема One Dark Pro
    github-theme.vsix     темы GitHub (Dark / Dark Dimmed / Light)
    tokyo-night.vsix      тема Tokyo Night
    catppuccin.vsix       темы Catppuccin (Latte / Frappe / Macchiato / Mocha)
    nord.vsix             тема Nord

  Требование: VS Code на машине B не старее 1.75 (февраль 2023).
  Проверить: Help -> About, либо в консоли  code --version


################################################################################
#  СПОСОБ 1 (ПРАВИЛЬНЫЙ) — через команду установки
#
#  ВАЖНО: просто скопировать .vsix в папку extensions НЕЛЬЗЯ — VS Code его
#  не увидит. .vsix — это zip-архив, его нужно именно УСТАНОВИТЬ, тогда
#  VS Code сам распакует его в %USERPROFILE%\.vscode\extensions и пропишет
#  в реестр расширений (extensions.json).
################################################################################

:: из cmd/PowerShell, указав путь к папке с файлами:

cd /d D:\transfer\vsix-offline
code --install-extension ruff-win32-x64.vsix
code --install-extension one-dark-pro.vsix
code --install-extension github-theme.vsix
code --install-extension tokyo-night.vsix
code --install-extension catppuccin.vsix
code --install-extension nord.vsix

:: затем перезапустить VS Code


################################################################################
#  СПОСОБ 2 — то же самое, но мышкой (если команда code недоступна)
################################################################################

  1. Открыть VS Code
  2. Панель расширений: Ctrl+Shift+X
  3. Меню "..." в правом верхнем углу панели -> "Install from VSIX..."
  4. Выбрать файл .vsix -> повторить для каждого
  5. Перезапустить VS Code


################################################################################
#  ПОСЛЕ УСТАНОВКИ
################################################################################

  1. Проверить Ruff: открыть любой .py, добавить строку "import os"
     (неиспользуемый импорт) — она должна подчеркнуться. Ctrl+S — исчезнет.

  2. Выбрать тему: Ctrl+K затем Ctrl+T, листать стрелками (живой предпросмотр).

  3. Перенести конфиги из корня проекта AItest (если их ещё нет на машине B):
       ruff.toml               -> в корень проекта
       .vscode\settings.json   -> в папку .vscode проекта
       RUFF_SETUP.md           -> справка, по желанию

  ЗАМЕЧАНИЕ по ruff.toml: там стоит target-version = "py39" (под Python на
  машине A). На машине B стоит Python 3.11 — если код запускается ТОЛЬКО там,
  поменяйте на "py311", тогда Ruff будет предлагать современный синтаксис
  (match, X | Y и т.д.). Если код гоняется и на 3.9 — оставить py39.


################################################################################
#  ЕСЛИ ПОНАДОБИТСЯ ДОКАЧАТЬ ДРУГОЕ РАСШИРЕНИЕ (на машине A)

:: универсальные расширения (темы и т.п.):
::   https://marketplace.visualstudio.com/_apis/public/gallery/publishers/{ИЗДАТЕЛЬ}/vsextensions/{ИМЯ}/{ВЕРСИЯ}/vspackage

:: платформо-зависимые (Ruff, Python, Pylance — содержат exe/dll):
::   тот же URL + ?targetPlatform=win32-x64
::   и версию нужно указывать точную, "latest" с targetPlatform не работает

:: издателя/имя/версию смотреть на странице расширения в маркетплейсе
:: (marketplace.visualstudio.com), поле "Unique Identifier" = издатель.имя
