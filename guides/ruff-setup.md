# Установка и настройка Ruff

Ruff — быстрый линтер и форматтер для Python. Заменяет Flake8, isort, pyupgrade,
Black и др. Конфигурация проекта уже лежит в корне: `ruff.toml` (правила) и
`.vscode/settings.json` (интеграция с VS Code).

## Шаг 1. Расширение VS Code (обязательно)

1. Открыть панель расширений: `Cmd+Shift+X`
2. В поиске набрать **Ruff**
3. Установить расширение от **Astral Software** (id: `charliermarsh.ruff`)

Либо из терминала:

```bash
code --install-extension charliermarsh.ruff
```

После установки открыть любой `.py`-файл — проблемные места подчеркнутся сразу.
Расширение содержит встроенный бинарник Ruff, поэтому **дальше можно ничего не
ставить** — линтер уже работает.

## Шаг 2. CLI-версия (опционально)

Нужна, если хотите запускать проверку из терминала или в CI.

```bash
# вариант 1: через Homebrew (глобально)
brew install ruff

# вариант 2: через pip
pip3 install ruff

# проверка
ruff --version
```

Если Ruff установлен в venv проекта, расширение VS Code автоматически использует
его вместо встроенного бинарника — версии в редакторе и в CI будут совпадать.

## Шаг 3. Проверить, что всё работает

1. Открыть любой `.py`-файл (например, `llm-chat-app/backend/app/main.py`)
2. Добавить в начало строку `import os` (если `os` не используется) —
   она подчеркнётся как неиспользуемый импорт
3. Нажать `Cmd+S` — строка исчезнет сама (автофикс при сохранении)

## Что происходит при сохранении (`Cmd+S`)

Настроено в `.vscode/settings.json`:

| Действие | Что делает |
|---|---|
| `source.fixAll.ruff` | исправляет всё, что Ruff умеет чинить сам |
| `source.organizeImports.ruff` | сортирует импорты |
| `formatOnSave` | форматирует код (отступы, кавычки, длина строки ≤ 100) |

Подсветка ошибок при этом работает постоянно, прямо во время набора текста —
сохранение нужно только для автоисправлений.

## Полезные команды CLI

```bash
ruff check .            # проверить весь проект
ruff check . --fix      # проверить и исправить всё исправимое
ruff format .           # отформатировать весь проект
ruff linter             # список всех групп правил
ruff rule F401          # описание конкретного правила
```

## Где менять правила

Все правила — в `ruff.toml` в корне проекта. Сейчас включены группы:
`E`, `W` (стиль), `F` (баги импортов/переменных), `I` (импорты),
`UP` (устаревший синтаксис), `B` (вероятные баги), `SIM` (упрощение),
`C4` (comprehensions). Полный каталог: https://docs.astral.sh/ruff/rules/
