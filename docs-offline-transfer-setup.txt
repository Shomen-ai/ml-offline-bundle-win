  ГЛАВНОЕ ПРАВИЛО: колёса (.whl) привязаны к платформе и версии Python.
  Поэтому на машине A всегда качаем с явным указанием цели:
      --only-binary=:all: --platform win_amd64
      --python-version 311 --implementation cp --abi cp311
  Тогда неважно, какая ОС и какой Python на самой машине A.

  Ориентировочный объём: ~6-7 ГБ (из них ~5 ГБ — файл модели).

################################################################################
#  ЧАСТЫЕ ПРОБЛЕМЫ ПРИ ОФЛАЙН-ПЕРЕНОСЕ
################################################################################

"ERROR: Could not find a version that satisfies the requirement X"  при install
    -> зависимости X нет в папке wheels. На машине A:
       pip download X --only-binary=:all: --platform win_amd64
          --python-version 311 --implementation cp --abi cp311 --dest D:\transfer\wheels

"is not a supported wheel on this platform"
    -> колесо скачано под другой Python/архитектуру. Проверить, что на машине A
       были указаны --python-version 311 --abi cp311 --platform win_amd64,
       а на машине B  python --version  действительно показывает 3.11.

"ERROR: Some externally-hosted files were ignored" / pip пытается в сеть
    -> забыт --no-index. Без него pip при малейшей заминке уходит на PyPI.

pip начал что-то СОБИРАТЬ из исходников
    -> в папку попал .tar.gz вместо .whl. На машине A обязателен
       --only-binary=:all: , иначе pip качает исходники для пакетов без колёс.

llama_supports_gpu_offload() == False
    -> перенесли CPU-колесо. Смотреть имя файла: в нём должно быть cu118.
       Перекачать с --index-url (не --extra-index-url) на индекс cu118.

pip обновил пакеты, которые трогать не хотелось
    -> забыт -c constraints.txt на шаге A1. Откатиться:
       pip install --no-index --find-links=D:\transfer\wheels -r constraints.txt

DPI-1047 "Cannot locate a 64-bit Oracle Client library"
    -> неверный путь в init_oracle_client. Сверить через  dir D:\oracle
       (каталог может называться instantclient_19_31, а не как в примере).

Модель весит меньше, чем на машине A / не грузится
    -> файл побился при копировании. Сверить SHA256 (certutil -hashfile).
